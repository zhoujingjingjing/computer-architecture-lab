## 1. 引言

在本实验中，你将亲手使用一个真实的存内计算（processing-in-memory, PIM）架构。你将针对多个工作负载编程 UPMEM PIM 架构 [1][2][3][4] 并进行实验。你的主要目标是：(1) 熟悉 UPMEM PIM 系统组织（作为真实内存中心计算系统的示例），(2) 理解 UPMEM 编程模型并编写自己的代码，(3) 理解 UPMEM PIM 核（称为 DRAM 处理单元，DPU）的微架构和指令集架构（ISA）。

正如课堂上介绍的，UPMEM PIM 架构由多个 DPU（最多 2,560 个）组成，每个 DPU 都可以访问自己的 DRAM 组（称为主 RAM，MRAM）和自己的暂存存储器（称为工作 RAM，WRAM）。你可以在 [3][4] 中找到 UPMEM PIM 系统的完整描述。

## 3. 你的任务 1/4：在主存与支持 PIM 的内存之间传输数据

你的目标是熟悉主机主存与支持 PIM 的内存之间的不同类型的数据传输。我们为此任务提供了模板。更多细节见第 8 节。

你的任务如下：

1. 编写一个主机程序，练习主机主存与一个或多个 MRAM 组之间的所有类型数据传输。具体来说，有三种类型的数据传输 [2]：(1) 串行（serial），(2) 并行（parallel），(3) 广播（broadcast）。串行和并行传输把数据从主存移到 MRAM 组，反之亦然。广播传输只能从主存到 MRAM 组。

## 4. 你的任务 2/4：AXPY

你的目标是熟悉 DPU 内核启动与执行，以及不同数量的 PIM 线程（在 UPMEM 架构中称为 tasklet）下的性能扩展。我们为此任务提供了模板。更多细节见第 8 节。

你的任务如下：

1. 编写一个 DPU 内核，对向量的每个元素执行 AXPY 运算（y = y + alpha × x）[6]。你必须 (1) 把两个输入向量 Y 和 X 传输到 MRAM 组，(2) 使用可变数量的 tasklet 执行 AXPY 运算，(3) 把结果写入输出向量 Y，(4) 把输出向量传回主机主存。
2. 按需分配尽可能多的 WRAM，并使用 mram_read 和 mram_write 在 MRAM 和 WRAM 之间移动数据。
3. 你的代码应该对任何数据类型（例如 char、short、int、long long int、float、double）和向量大小产生正确结果。提示：确保所有数据传输都是 8 字节对齐的 [2]。
4. 在 1 到 24 之间的所有 tasklet 数量下运行你的内核，并确保内核在所有情况下（即任何数量的 tasklet 和 DPU）都产生正确结果。输入向量至少为 8 MB（每个 DPU）。

基于你的分析，请在实验报告中提交以下问题的答案。

## 6. 你的任务 4/4：向量归约

你的目标是熟悉 DPU 内部（即跨 tasklet）通信的同步原语。为此，你将编写一个 DPU 内核，执行输入向量的并行归约。

## 7. 加分任务：实现 RGB 到灰度转换

在此任务中，你的目标是在可变数量的 DPU 上实现图像的 RGB 到灰度转换 [7]。图像应该有 8 位红、绿、蓝通道。对于每个图像像素，你执行一次转换，从 R、G、B 值得到灰度值。比较以下三种方法：

1. 亮度法（Lightness）：grayscale = min(R,G,B) + max(R,G,B) / 2
2. 平均法（Average）：grayscale = (R + G + B) / 3
3. 感知亮度法（Luminosity）：grayscale = 0.3 × R + 0.59 × G + 0.11 × B

基于你的分析，请在实验报告中提交以下问题的答案。

1. 不同方法在不同 tasklet 数量下如何扩展？
2. 哪种方法最快？解释。
3. 哪种方法最慢？解释。

### 8.2. 编译

**任务 1。** 任务 1 的 Makefile 包含以下输入参数和默认值：

- `NR_DPUS ?= 1`：程序将使用的 DPU 数量。
- `NR_TASKLETS ?= 16`：程序将使用的每个 DPU 的 tasklet 数量。
- `TRANSFER ?= PARALLEL`：数据传输类型（SERIAL、PARALLEL、BROADCAST）。
- `PRINT ?= 0`：打印 DPU 内核的日志。

对于任务 1，你只需使用 TRANSFER 和 NR_DPUS。使用默认参数编译：

```
$ make
```

例如，使用串行传输和 64 个 DPU 编译：

```
$ NR_DPUS=64 TRANSFER=SERIAL make
```

编译后的二进制文件将在 bin 文件夹中。你可以用默认输入运行程序：

```
$ ./bin/host_code
```

你可以用 -h 查看可能的输入参数：

```
$ ./bin/host_code -h
```

例如，你可以运行程序在主机主存和 MRAM 组之间（以及反向）传输 2 MB 数据（即 262144 个 64 位元素），并在 2 次预热后重复实验 10 次：

```
$ ./bin/host_code -w 2 -e 10 -i 262144
```

**任务 2 及后续任务。** 任务 2 的 Makefile 包含以下输入参数和默认值：

- `NR_DPUS ?= 1`：程序将使用的 DPU 数量。
- `NR_TASKLETS ?= 16`：程序将使用的每个 DPU 的 tasklet 数量。
- `BLOCK ?= 10`：在 MRAM 和 WRAM 之间移动的数据块（chunk）大小。实际字节数是 2^BLOCK。
- `TYPE ?= INT32`：输入数组的数据类型（CHAR、SHORT、INT32、INT64、FLOAT、DOUBLE）。
- `TRANSFER ?= PARALLEL`：数据传输类型（SERIAL、PARALLEL）。
- `PRINT ?= 0`：打印 DPU 内核的日志。
- `PERF ?= NO`：使用性能计数器统计周期或指令数（CYCLES、INSTRUCTIONS）。

使用默认参数编译：

```
$ make
```

例如，使用并行传输、64 个 DPU、每个 DPU 12 个 tasklet、32 位浮点数据类型、512 字节 MRAM-WRAM 和 WRAM-MRAM 数据传输、并统计 tasklet 执行的指令数来编译：

```
$ NR_DPUS=64 NR_TASKLETS=12 BLOCK=9 TYPE=FLOAT TRANSFER=PARALLEL PERF=INSTRUCTIONS make
```

与任务 1 一样，编译后的二进制文件将在 bin 文件夹中。例如，你可以运行 AXPY 程序处理 4 MB 数组（例如 1048576 个 32 位浮点元素），alpha 值等于 20，并在 2 次预热后重复实验 10 次：

```
$ ./bin/host_code -w 2 -e 10 -i 1048576 -a 20
```
